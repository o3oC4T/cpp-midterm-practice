# C++ 중간고사 연습실

교수님 강의자료를 바탕으로 컴퓨터언어 II 중간고사를 준비하는 PC용 학습 사이트입니다.

[문제 풀기와 핵심 암기](https://o3oc4t.github.io/cpp-midterm-practice/)

- 25문제: OX 10, 4지선다 4, 함수 빈칸 3, 값 추적 4, 오류 수정 2, 서술형 2
- 핵심 암기 47개: 기초 보충 4개와 강의 1~5장 요약 43개
- [클래스 이해하기](https://o3oc4t.github.io/cpp-midterm-practice/classes.html): Circle 예제로 배우는 9단계 설명, 한 줄씩 실행 흐름 추적, 두 객체의 반지름 조작, 이해 확인 5문항
- [4장 객체 포인터·동적 생성](https://o3oc4t.github.io/cpp-midterm-practice/objects.html): 10단계 설명, 포인터 대상 변경 실습, 단일 객체·배열의 생성/소멸 추적, 이해 확인 6문항
- 문제·암기카드별 강의 PDF 쪽수 표시
- 자동 채점, 해설, 오답노트, 북마크, 답을 가리는 암기카드
- 오류 수정·서술형은 모범답안과 비교하여 직접 채점
- 학습 기록은 브라우저에 자동 저장

## 강의 기반 구성

제공된 2026년 강의 PDF 1~5장과 4·5장 추가 코드의 개념·실습을 바탕으로 새로 작성한 연습문제입니다. 실제 시험 기출문제나 출제 예고는 아닙니다. 표시한 쪽수는 PDF 첫 페이지를 1쪽으로 센 값입니다.

| 자료 | 반영한 주요 내용 |
| --- | --- |
| 1장 · C++의 시작 | 번역·링크, 설계 목표, 객체 지향, 표준 라이브러리 |
| 2장 · C++ 프로그래밍의 기본 | 전처리, 이름 공간, 입출력, C 문자열과 string |
| 3장 · 클래스와 객체 | 생성·소멸, 위임 생성자, 초기화 목록, inline, 헤더 분리·포함 가드 |
| 4장 · 객체 포인터와 객체 배열·객체의 동적 생성 | 객체 포인터, new/delete, this, 문자열 처리, CSV 출력 추가 실습 |
| 5장 · 함수의 참조·복사 생성자 | 값 전달의 복사 생성, 참조·참조 반환, 깊은 복사, NRVO, CSV 입력 추가 실습 |

시험 범위는 Chap. 0~5입니다. 제공된 `0a`는 강의 안내이며, 여기서 별도로 언급한 `00_C++ 기초 학습` 파일은 확인되지 않았습니다. 따라서 기초 보충 4개는 해당 강의 요약으로 표시하지 않습니다. 리터럴·자료형 크기 구별은 앞선 학기 시험 형식의 참고용입니다.

강의에 소개된 상속·다형성·템플릿은 개념만 다룹니다. CSV 입출력은 4·5장 PDF 및 추가 코드에 포함된 실습이므로 해당 장의 추가 실습으로 표시합니다. 강의 원문 PDF, 추가 코드 ZIP, 학생 명단과 개인 과제는 배포하지 않습니다.

값 매개변수의 복사 생성과 일반 생성자를 구별하고, NRVO를 이동 생성자의 필수 호출로 설명하지 않습니다. NRVO 및 Visual Studio 옵션의 의미는 [Microsoft의 /Zc:nrvo 설명](https://learn.microsoft.com/en-us/cpp/build/reference/zc-nrvo?view=msvc-170)으로 확인했습니다. 기초 보충의 문자 리터럴은 [Microsoft의 문자·문자열 리터럴 설명](https://learn.microsoft.com/en-us/cpp/cpp/string-and-character-literals-cpp?view=msvc-170)을 참고했습니다.

## 채점과 저장

빈칸·출력값은 등록된 정답과 동등 표현으로 채점합니다. 코드 빈칸의 공백·마지막 세미콜론 및 출력의 공백·줄바꿈 차이는 무시합니다. 등록되지 않은 동등한 답은 해설과 비교하여 직접 정답으로 표시할 수 있습니다.

학습 기록은 서버로 전송되지 않습니다. 같은 브라우저·사이트 주소에서 이어지며 사이트 데이터 삭제 시 사라집니다. 강의 기반 문제 개편판은 전용 저장 키 `lecture-v2`를 사용하여 변경 전 문항의 답안을 새 문항에 적용하지 않습니다.

## 실행과 검증

외부 라이브러리와 빌드가 필요 없는 정적 HTML/CSS/JavaScript입니다.

```sh
npm start
# http://localhost:4173
npm test
```

GitHub Pages는 `main` 브랜치의 `/docs`를 사용합니다.

- `docs/classes.html`, `docs/class-content.js`, `docs/classes.js`: 클래스 설명과 실습 화면
- `docs/class-model.js`: 예제 코드 및 객체 상태 시각화
- `docs/objects.html`, `docs/object-content.js`, `docs/objects.js`: 4장 설명과 실습 화면
- `docs/object-model.js`: 포인터, 동적 객체, 배열의 상태 및 생성·소멸 순서
- `docs/questions.js`: 25문제와 정답·해설
- `docs/memory.js`: 파트별 요약·암기카드 47개
- `docs/sources.js`: 강의자료 정보와 쪽수 표기
- `docs/engine.js`: 채점·기록 복원·통계
- `docs/app.js`: 화면과 학습 흐름
- `tests/engine.test.js`: 채점·저장·자료 참조 검증

빈칸 완성·출력 추적·오류 수정 후 코드와 NRVO 설정 차이 등 14건을 GCC C++17 및 AddressSanitizer·UndefinedBehaviorSanitizer로 실행 검증했습니다. Node 테스트 18건과 PC Chromium에서 25문제 채점, 47개 암기카드, 저장·복원, 오답노트 흐름을 확인했습니다.

클래스 설명은 교수님 3장 Circle 예제를 바탕으로 새로 구성했습니다. 실습의 상태 변화는 지정된 C++ 예제를 시각화한 것이며 임의의 C++ 코드를 실행하는 컴파일러는 아닙니다. C++14로 전체 추적 코드·생성/소멸 코드·클래스 밖 구현을 실행하고, 두 객체에 0~8을 각각 전달하는 18회 호출 결과를 시각화와 대조했습니다. PC 브라우저에서 9개 설명, 앞/뒤 추적, 초기화, 이해 확인 5문항과 기존 학습 화면 연결을 검증했습니다.

4장 설명은 교수님 강의 3~28쪽의 객체 포인터, 객체 배열, new/delete, CircleManager 내용을 바탕으로 구성했습니다. C++14 예제 7개를 AddressSanitizer·UndefinedBehaviorSanitizer로 실행하고, 포인터 실습의 18회 호출 결과를 시각화와 대조했습니다. 해제 후 객체 접근, 중복 해제, 시작 주소가 아닌 포인터 해제 등 잘못된 코드는 설명으로만 다루며 실행하지 않습니다.
