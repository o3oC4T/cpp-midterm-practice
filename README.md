# C++ 중간고사 연습실

컴퓨터언어 II 중간고사를 준비하는 PC용 문제풀이·핵심 암기 웹사이트입니다.

- 문제 25개: OX 10, 4지선다 4, 함수 빈칸 3, 값 추적 4, 오류 수정 2, 서술형 2
- 파트별 핵심 암기 32개: C 기초 복습, C++ 시작, 입출력, 클래스, 객체 활용, 참조와 복사
- 객관식·빈칸·출력값 자동 채점과 설명, 오류 수정·서술형 직접 채점
- 오답노트, 북마크, 핵심 요약, 답을 가리는 암기카드
- 답안과 암기 완료 기록을 브라우저 localStorage에 저장

## 범위

교재 1~5장과 수업 실습의 개념에 기반한 창작 연습문제이며 실제 시험 기출문제가 아닙니다. 시험 안내의 Chap. 0 별도 자료는 제공되지 않아, 해당 기초 부분은 C언어 복습 수준으로 구성했습니다. 교재 원문 PDF와 개인 과제 파일은 포함하지 않습니다.

객관식은 선택한 답을, 빈칸과 출력 문제는 명시된 정답 및 동등 표현을 기준으로 채점합니다. 코드 빈칸의 공백과 마지막 세미콜론, 출력값의 공백·줄바꿈 차이는 무시합니다. 자동 채점이 인식하지 못하는 동등 표현은 해설과 비교해 직접 정답으로 표시할 수 있습니다. 서술형과 오류 수정은 직접 채점합니다.

## 실행과 검증

빌드와 외부 라이브러리가 필요 없는 정적 HTML/CSS/JavaScript입니다.

```sh
npm start
# http://localhost:4173

npm test
```

GitHub Pages는 `main` 브랜치의 `/docs` 폴더를 사용합니다. 브라우저 데이터는 사이트에서 서버로 전송하지 않습니다. 같은 브라우저·사이트 주소에서만 기록이 이어지며, 기록 초기화 또는 사이트 데이터 삭제 시 사라집니다.

## 구성

- `docs/questions.js`: 25문제와 정답·해설
- `docs/memory.js`: 파트별 요약과 암기카드
- `docs/engine.js`: 채점, 기록 복원, 통계
- `docs/app.js`: 화면과 학습 흐름
- `tests/engine.test.js`: 채점 및 저장 데이터 검증

출력 추적 문제의 C++ 코드는 개별 컴파일·실행으로 결과를 확인했습니다.
